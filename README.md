# 梦境回廊 · 灰壤门（V8）

放置经营网页游戏「梦境回廊」第一扇门——**灰壤门**的完整可玩实装（V8）。纯前端单文件，无需构建，`index.html` 直接打开或部署到任意静态托管即可运行。

在线游玩：https://elangzhiya.github.io/Dream-Corridor/

## 内容
- **38 座建筑 / 五纪元科技树**（农耕 → 铁工 → 电气 → 融合 → 核能），建筑升级由研究触发
- **14 个兵种**，双轨士兵系统：数字编制士兵（批量招募、有战死）+ 英雄（上限 10、永不战死只疗伤、8 装备槽、白绿蓝紫金 5 品级、自动打怪换装）
- **12 块故土**（四层结构），收复后自动分兵驻守，强者往深处巡逻
- **产业链供货**：上游建筑给下游产能加成
- 荣光换门 / 信标跨门加成 / 回廊记事（故事叙事）/ localStorage 自动存档 + 12h 离线收益
- 全部资源整数化，大数以 K/M 缩写

## 文件
- `index.html` — 灰壤门 V8 完整实装（单文件游戏）
- `梦境回廊-灰壤门-V8实装.html` — 同上，具名副本便于下载辨识
- `梦境回廊-完整设定集-v8.html` — 完整世界观与机制设定集（含其余三扇门设定稿）
